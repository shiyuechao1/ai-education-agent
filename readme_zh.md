AI 教育智能备课与个性化学习辅导智能体

核心目标：面向教师备课、课堂教学、学生答疑、作业批改和个性化辅导场景，基于大语言模型、RAG 与 Agent 技术构建教育智能体平台。系统需支持教材/讲义入库、知识点检索、教案与课堂活动生成、学生问答、错题分析、练习推荐、教师管理端和学生端交互，使小组成员完成从 AI 能力设计到前后端工程落地的完整实践。
任务 1：建设课程知识库，支持教材 PDF、讲义、题库、教学目标等资料上传、解析、切分、向量化和关键词检索，实现带引用来源的 RAG 问答。
任务 2：实现智能备课模块，教师输入年级、学科、章节和教学目标后，自动生成教案、课堂导入、讲授提纲、互动问题、板书要点和分层练习。
任务 3：实现个性化学习 Agent，根据学生错题、薄弱知识点和学习记录，调用知识检索、题目生成、解析生成、学习路径规划、教学数据 SQL Agent 和流式语音问答工具，输出个性化辅导方案。
任务 4：实现学生端问答与练习页面，支持多轮追问、答案引用、相似例题、错题收藏和学习记录查看。
任务 5：实现教师/管理员后台，支持教师管理、学生管理、班级管理、课程管理、题库管理、学习记录管理和知识库管理。

1. 需求分析与角色设计：明确教师、学生、管理员三类角色的业务流程，完成页面原型、接口清单和核心数据表设计。
2. 系统架构设计：采用前后端分离架构，后端提供用户认证、文件上传、知识库管理、模型调用、Agent 编排和业务数据接口；前端提供学生端、教师端和后台管理端。
3. RAG 功能实现：完成资料解析、文本清洗、分块、向量索引、检索重排、引用展示和无关问题拒答逻辑。
4. 大模型能力实现：设计教案生成、题目生成、答案讲解、错因分析、学习建议等提示词模板，并输出结构化结果。
5. Agent 工作流实现：将知识检索、题目生成、学习路径规划、教学数据 SQL Agent、流式语音问答和报告生成等能力封装为工具，支持任务状态记录和失败重试。
6. 前端功能实现：完成登录、课程选择、智能问答、备课生成、练习推荐、历史记录、反馈评价和可视化看板。
7. 后端管理实现：完成教师、学生、班级、课程、题库、学习记录和知识库等业务对象管理。
8. 系统联调：保证前端、后端、向量库、关系数据库和模型服务可以完整串联，形成可演示系统。
